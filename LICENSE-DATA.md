# Data attribution

- Geography metadata: [mledoze/countries](https://github.com/mledoze/countries), countries.json, retrieved 2026-10-08. Open Database License (ODbL) 1.0. Existing source URLs/checksums are in geographySource.
- Airport coordinates: [OpenFlights](https://openflights.org/data.php), airports.dat, retrieved 2026-10-08, ODbL 1.0. Locations do not establish operating routes. The extracted geography/airport database is offered under the same ODbL license; individual contents are subject to the Database Contents License.
- Administrative locations: [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database), states.json, retrieved 2026-10-08. ODbL 1.0. Extracted administrative database under the same license. Source bytes were validated against recorded checksums.
- City names/coordinates: [GeoNames](https://www.geonames.org/) via [lutangar/cities.json](https://github.com/lutangar/cities.json), retrieved 2026-10-08, Creative Commons Attribution 4.0. The geographic index and selected profiles are adapted subsets, with retained source attribution.
- UNESCO factual metadata: historical 2024 export, [primary syndication source](https://whc.unesco.org/en/syndication), obtained through [WorldHeritageApp/source_material](https://github.com/simao-g/WorldHeritageApp/tree/main/source_material). The mirror was retrieved 2026-10-08; retrieval does not establish that its contents are the current list. Names, inscription years, categories, coordinates and official detail URLs are used. Full copyrighted descriptions and photos are not republished. Dutch notes are factual paraphrases; tags are derived from categories and descriptions. Check current primary terms and status at [UNESCO](https://whc.unesco.org/). The mirror's public availability is not represented as a license for all text or images. Country assignments for Curaçao/Puerto Rico are adapted to the physical location in the planner; UNESCO state-party classification can differ.
- Climate summaries: [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), explicit ERA5 model, 2015–2024. Attribution: Open-Meteo, [Copernicus Climate Change Service / ECMWF ERA5](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview). API data license: Creative Commons Attribution 4.0, with Copernicus attribution. Monthly aggregation is an adaptation of reanalysis, not national averages or local measurements. Nearby profiles may use the same named reference series; this is disclosed rather than represented as newly observed local data.

No provider endorses the planner. Source URLs, retrieval dates, SHA-256 hashes and climate processing metadata are recorded in the respective source modules and scripts.
