# Data attribution

Geographic metadata in geography.mjs is adapted from [mledoze/countries](https://github.com/mledoze/countries), countries.json, retrieved 2026-10-08. Source license: Open Database License (ODbL) 1.0, https://opendatacommons.org/licenses/odbl/1-0/. Source checksums and URLs are included in geographySource.

Airport coordinate records in geography.mjs are adapted from [OpenFlights](https://openflights.org/data.php), https://github.com/jpatokal/openflights/blob/master/data/airports.dat, retrieved 2026-10-08, under ODbL 1.0. The extracted geographical/airport database is offered under the same ODbL license. Individual database contents are subject to the Database Contents License: https://opendatacommons.org/licenses/dbcl/1-0/.

Climate summaries in climate-data.mjs are derived from [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), with explicit ERA5 model selection and reference coordinates, 2015–2024. Attribution: Open-Meteo, https://open-meteo.com/, [Copernicus Climate Change Service / ECMWF ERA5](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview). API data license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Monthly processing and retrieval dates are documented in each source record and scripts/import-climate.py. These processed values have been modified by monthly aggregation; they are not national averages or local weather-station observations. Neither provider endorses this planner.

Descriptive highlights, interest ratings, boat route concepts, cost models and travel-time formulas are editorial application content, rather than facts supplied or endorsed by the database providers. Refer to the application and README for their limits.
